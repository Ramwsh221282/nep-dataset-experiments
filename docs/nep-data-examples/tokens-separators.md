Основные разделители которые присутствуют в обучающих данных.

| Текст разделителя       | Назначение                                                         |
| ----------------------- | ------------------------------------------------------------------ |
| `<                      | fim_suffix                                                         | >`     | Начало секции suffix — неизменяемого хвоста текущего исходника               |
| `<                      | fim_prefix                                                         | >`     | Начало секции с контекстом, историей и размеченной частью текущего исходника |
| `<                      | fim_middle                                                         | >`     | Конец промпта и позиция, с которой модель начинает генерировать ответ        |
| `<                      | file_sep                                                           | >`     | Заголовок файла или служебной секции: сразу после него идёт имя, затем `\n`  |
| `<filename>`            | Альтернативное написание заголовка, сохранённое в части источников |
| `<                      | marker_1                                                           | >`, `< | marker_2                                                                     | >`, … | Границы редактируемых регионов внутри текущего исходника |
| `<                      | user_cursor                                                        | >`     | Положение курсора; в корректном входе и ответе присутствует ровно один раз   |
| `<                      | endoftext                                                          | >`     | EOS: завершение ответа модели                                                |
| `<[begin▁of▁sentence]>` | Необязательный сохранённый префикс BOS в некоторых источниках      |

Это текстовые написания элементов протокола. Не нужно предполагать, что каждое из них обязательно представлено одним ID токенизатора.
