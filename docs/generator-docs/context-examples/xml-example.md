# XML

Контекст для изменения версии зависимости:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
  <dependencies>
    <dependency>
      <groupId>org.example</groupId>
      <artifactId>client</artifactId>
      <version>2.1.0</version>
    </dependency>
  </dependencies>
</project>
```
