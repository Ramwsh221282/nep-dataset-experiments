# Требования к контексту текущего файла и других файлов в промпте

Для функций и методов сохранять имя, параметры, возвращаемый тип, ограничения обобщённых типов и необходимые модификаторы. Тела функций и методов не включать: оставлять сигнатуры. Связанные декораторы и атрибуты можно сохранять.

Для классов, структур и типов сохранять релевантные поля с типами и объявления методов. Объявления переменных и их значения включать. Если значение — функция, сохранять её сигнатуру без реализации. Для JSX/TSX дополнительно сохранять релевантную разметку и связанные с ней объявления внутри компонента.

Обработанный контекст — сокращённое представление исходника, не обязательно самостоятельный компилируемый файл.
